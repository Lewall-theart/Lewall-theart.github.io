Nhận diện chiến trường

Challenge trao cho tôi ba tham số RSA. Không thêm, không bớt:

RSA Parameters 
n = 625884537996922021301000341433932506927375585765524880339...

Mục tiêu rõ ràng: tìm m = cᵈ mod n. Để tính d thì cần φ(n) = (p−1)(q−1). Và để có φ(n) thì phải phân tích n thành p × q.

Làm sao phân tích một số 1024-bit+ mà không có supercomputer?

§ 03
STEP 03

Kế hoạch tấn công

Từ hai manh mối cốt lõi, cấu trúc của n lộ ra hoàn toàn:

n = p × q
với  p ≈ 2777  (~777 bit)  ·  q < 100.000

RSA đặt toàn bộ sức mạnh vào việc p và q đều lớn và ngẫu nhiên. Khi một trong hai nhỏ tới mức có thể brute-force — mọi thứ sụp đổ trong tích tắc.

01
Trial Division Thử chia n cho toàn bộ số nguyên tố dưới 100.000. Nếu tìm được q thì p = n / q tức thì.
02
Tính φ(n) Với p và q đã biết: φ(n) = (p−1)(q−1)
03
Tìm private key d d = e⁻¹ mod φ(n) — nghịch đảo modular chuẩn.
04
Giải mã m = cᵈ mod n, rồi chuyển số thành bytes để lấy flag.
§ 04
STEP 04

Thực thi — từng dòng lệnh

Không cần tool phức tạp. Một script Python ngắn là đủ để phá vỡ toàn bộ hệ thống mã hóa này.

Phân tích n:

Python · Factorization 
from sympy import primerange

n = 625884537996922021301000341433932506927375585765524880339...
e = 0x10001
c = 623187221058644756330702672479741021304925868602233957500...

# Sofia said q < 100000 — let's brute force it
for q in primerange(2, 100_000):
    if n % q == 0:
        p = n // q
        print(f"✓ Factor found: q = {q}")
        print(f"  p = {p}")
        break

Recover private key và decrypt:

Python · Decrypt RSA 
from Crypto.Util.number import inverse, long_to_bytes

# Compute Euler's totient
phi = (p - 1) * (q - 1)

# Private exponent: d = e⁻¹ mod φ(n)
d = inverse(e, phi)

# Decrypt: m = c^d mod n
m = pow(c, d, n)
flag = long_to_bytes(m)

print(f"Flag: {flag.decode()}")

Toàn bộ quá trình — từ trial division đến có flag — mất chưa tới 1 giây.
Một hệ thống mã hóa được xây dựng nhiều giờ, sụp đổ trong chớp mắt.
